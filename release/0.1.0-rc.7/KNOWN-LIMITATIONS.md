# Known limitations: 0.1.0-rc.7

- Clean Windows installation, upgrade, uninstall, and restart acceptance remain
  `PENDING`.
- Complete user release signoff remains `PENDING`.
- The formal default entry and default traffic remain closed.
- Background write, coordinator recovery, and automatic hardware changes remain
  closed.
- Real Thread execution is not part of this release build or automated gate.
- The panel is promised only for the current Codex conversation.
- DSH and other Agent hosts receive no SkillDock panel promise.
- A separate local-Node edition and automatic local-Node selection remain
  deferred; this package uses the frozen bundled Node runtime.
- PCHW chart data-series colors remain separate from the SkillDock application
  palette.
