# 使用方式

当前 `2.8.0` 为测试版且尚未正式发布。本文只描述已经交付或当前候选包中实际存在
的用户路径。

## 三种使用入口

- **Codex + SkillDock。** 适合在 Codex 当前对话中提交 CSV、查看图表和复制结论。
- **DSH core-only。** 适合在 DeepSeek Harness 中使用 PCHW 的聊天、采集和 CSV
  分析；没有 SkillDock 面板。
- **简易便携包。** 不依赖 Skill 宿主，直接运行本机只读采集与报告工具。

按实际使用的宿主选择包；同一个宿主的 Skill 扫描目录只保留一个活动版本。

## 在 Codex 中调用

```text
$pc-hardware-workbench
```

可以直接描述目标，不必先判断应该走哪条流程：

- “帮我看看当前电脑的硬件配置。”
- “游戏里偶尔卡顿，先帮我判断还缺哪些证据。”
- “这份 HWiNFO CSV 里有没有异常趋势？”
- “我想给这张显卡降温，先确认能不能安全调参。”
- “现在这套配置值得升级显卡还是继续保留？”

## SkillDock 操作面板

需要图表、证据对照或连续操作时，可以直接在 Codex 当前对话中说：

```text
这份 HWiNFO CSV 显示游戏二十分钟后掉帧。请打开 SkillDock 做图形化分析。
```

普通用户不需要启动 runner、记端口、创建 token 或设置测试开关。

1. Codex 先询问是否打开本地图形化分析；
2. 同意后，面板带入当前问题、Task 和可用附件；
3. 用户上传 CSV，或选择对话中已经提供的附件；
4. 首次本地分析弹出权限卡，选择“仅本次允许”；
5. 页面显示真实 SVG、具体判断、支持/冲突/背景证据和不确定性；
6. 结果写回后页面自动更新，不需要按 F5；
7. 用户复制结果回到当前 Codex 对话，或继续在面板补充问题；
8. 关闭并重启 SkillDock 后，同一 Task、附件、图表和结论仍可恢复，不创建
   第二个 Thread。

本版只有 Codex 当前对话承诺 `pchw-source-hosted` 面板。DSH 和其他宿主可以使用
PCHW 的聊天、采集和 CSV 分析，但不提供这个面板。

出现以下情况时回到普通对话即可：

- 不准备授予本地分析权限；
- SkillDock 未安装或无法启动；
- 当前已有另一个工作区面板；
- 页面加载失败或结果没有返回。

在 Codex 的 “Ask for approval” 模式下，如果交互式浏览器交接失败，Skill 会提示
“手动打开面板”。此时使用页面提供的短期链接或本地 `.url` 快捷方式打开同一面板，
再继续 CSV 提交和一次性权限。

面板不会自动修改 BIOS、固件、驱动、频率、电压、功耗、风扇或内存时序。

## DSH core-only

DSH 中只提供 PCHW Skill 的聊天、采集和 CSV 分析能力。调用：

```text
/pc-hardware-workbench
```

DSH 不安装、不启动 SkillDock Runtime，也不承诺 `pchw-source-hosted` 面板。

## 简易便携包

运行 `portable\开始使用.cmd` 后，选择标准或隐私脱敏模式，并明确同意只读采集。
便携包不需要 Codex 或 DSH，也不会自动修改任何硬件设置。

## 常见输入

Skill 可以处理对话描述、硬件报告、CSV、传感器快照、事件日志引用、截图说明和
手动填写的基线。图片只作为有限证据；CSV 和时间序列仍是趋势判断的基础。

如果信息不足，Skill 会给出最小补证动作，而不是直接猜测参数。

## 调参请求

调参请求至少需要：

- 电脑形态与主要硬件；
- 当前稳定状态；
- 当前控制值；
- 固定测试场景；
- 恢复路径和中止条件。

信息不足时不会生成可直接套用的数字。条件齐全后，也只提供一个单变量、可回退的
测试计划，由用户手动应用。

## 调试记录与恢复

当排查会跨多轮、使用多份证据、包含一次参数变更，或需要防止聊天上下文丢失时，
Skill 会在私有本地目录维护一个案卷。案卷记录当前目标、证据 ID、基线、实验、
通过/中止条件、恢复方式和下一步，但不会逐轮保存整段聊天。

开始新对话时可以直接说“从上次的 case 恢复”。紧凑 `Resume` 摘要会给出现场状态，
同时要求重新确认当前设置和证据新鲜度。原始 CSV、截图或日志只有在用户同意后才复制
进案卷。

## 排障请求

请描述最接近的现象、发生时间和最近的软硬件变化。存在焦味、液体、破损、鼓包或
异常高温时，Skill 会优先停止性能测试并提示处理物理安全问题。

## 遥测分析

优先提供原始 CSV 或结构化 `SensorSnapshot`。单张监控截图可以描述某个瞬间，但
不能代替时间窗口、采样间隔和缺失值记录。

## 隐私

硬件报告只读、默认省略序列号，并在脱敏模式下遮蔽可识别的设备字段。公开报告前
仍应人工检查。详见 [隐私与安全边界](privacy-and-safety.md)。
