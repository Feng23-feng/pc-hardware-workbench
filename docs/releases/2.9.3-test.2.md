# PC Hardware Workbench 2.9.3-test.2

这是 PCHW 的公开 Pre-release 测试版，用于真实用户反馈和逐步补充环境覆盖。
它不是正式稳定版。

## 本版重点

- Runtime 只保留窄范围物理安全兜底；普通权限、证据或调校门禁的 `blocked`
  状态不会被替换成断电建议；
- 当前用户的 `packet.text`、`packet.free_text`、当前 `user_message` 事件、
  原始 objective 和 Agent current goal 共同参与当前安全判断；
- 混合危险逐项判断，否定一种危险不会掩盖同句中的其他真实危险；
- 确认物理危险时使用固定安全停止动作，不保留可能冲突的 Agent detail；
- Summary-only 分析在归一化前验证 analyzer 顶层来源 SHA-256 和字节数；
- normalizer 和 chart pack 拒绝跨文件 ChartData，并统一使用一次分析产生的
  图表窗口；
- 普通文本分析默认返回 Summary-only；交互式图表动作显式请求 `FirstPass`；
- Collector 支持探针级 `-Sections` 过滤；
- Shared Evidence Store 首次真实写入时才创建。

## 已知限制

- `SKIP`：Live LHM Web/WMI 需要已运行且明确授权的 LHM 进程；本轮环境未提供。
- `PENDING`：真实 Codex Thread 的完整权限允许/拒绝和恢复流程。
- `PENDING`：人工交互体验验收。
- `PENDING`：干净 Windows 用户环境安装、升级、修复和卸载。
- `PENDING`：多平台兼容性。
- `PENDING`：重新构建发行包后的实际 Edge 验收。

这些条目不会被自动测试 PASS 覆盖，也不会从后续 Release 中删除。

## 发布定位

本版按公开 Pre-release 发行，允许真实用户在实际环境反馈问题。后续稳定版仍需
补齐上述环境验收和反馈修复，但不再以无限期等待完整环境覆盖作为交付前提。
