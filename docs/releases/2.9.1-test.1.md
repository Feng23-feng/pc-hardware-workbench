# PC Hardware Workbench 2.9.1-test.1

这是独立 PCHW 测试版，不包含或重新打包 SkillDock。

## 本版重点

- 显存 profile 精确绑定规范 GPU 型号或受控别名，不再使用子串匹配。
- HWiNFO64 原始字段与 MSI Afterburner 显示口径必须同时匹配 profile 中记录的
  工具身份和版本。
- `provisional` profile 默认拒绝；显式允许时仍在 SVG 中标记为 provisional。
- GPU 调优总览继续把显存频率放在核心/有效频率之后，并修复平直显存曲线被
  零高度 SVG 滤镜裁掉的问题。
- 新增 FirstPass、GpuTuning、CpuTuning 证据图表包与独立调优结论 renderer。
