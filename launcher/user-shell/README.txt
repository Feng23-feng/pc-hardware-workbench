SkillDock 面板包（用于 Codex）+ 电脑硬件工作台
使用说明

本安装包用于已安装 Codex Desktop 的用户，会安装电脑硬件工作台 Skill 和本地
SkillDock Runtime。单独的 PCHW Skill 包和便携工具不在本安装包内，请在 Release
中按使用场景另行选择。

适用环境
========

需要 Windows 11 64 位、Codex Desktop 和 Microsoft Edge。
电脑硬件工作台只在 Codex 的当前用户对话中打开。

安装
====

1. 将整个压缩包解压到本机可写目录。
2. 双击 Install.cmd。
3. 等待安装窗口提示完成；安装过程中不要关闭窗口。

如果电脑已经装有旧版电脑硬件工作台，请不要先删除旧 Skill。Install.cmd 会自动
识别已有安装并执行安全升级；升级会先备份旧版本，并在替换失败时恢复。新版本
成功安装后，Runtime 程序备份只保留最近一个可回退版本；Task 数据和迁移数据备份
不会被自动删除。

打开电脑硬件工作台
==================

安装完成后，在 Codex 的当前对话中直接提出硬件问题，并同意打开图形界面。
例如：

    “我玩游戏约 20 分钟后掉帧，这是 HWiNFO CSV。
     可以在当前任务里打开电脑硬件工作台分析吗？”

Skill 会在当前对话中启动面板，并带入当前任务、问题和附件。不需要手动运行
SkillDock.exe，也不需要配置端口、令牌或环境变量。

提交数据与权限
==============

1. 在页面中选择 CSV。
2. 填写要分析的问题并提交。
3. 权限卡出现时选择“仅本次允许”。

这个授权只用于当前这次本地分析，不会变成长期权限。不要让他人或其他 Agent
代替你点击授权、提交或分析按钮。

同一附件成功完成一次本地分析后，重复分析时才可能出现“同一附件后续分析”。
它只在当前 Task 中对该 CSV 有效两小时；更换附件仍需重新选择“仅本次允许”。

自动打开失败时
==============

如果 Codex 的“请求批准”模式使页面无法自动打开，页面会提示：

    手动打开面板

此时使用提示中的短期链接或本地 .url 快捷方式打开同一面板。打开后继续在页面
完成 CSV 提交和“仅本次允许”授权。

如果遇到运行环境不可写、任务工作区冲突或面板无法启动，请留在当前 Codex
对话继续处理，不要创建第二个任务或对话。

查看结果
========

分析完成后，页面应显示真实图表、针对当前数据的结论、支持与冲突证据、
不确定性以及低风险建议。结果回传后页面会自动更新。

关闭并重新打开后，同一任务、附件、图表和结论应恢复。

本地存储
========

页面右上角的“本地存储”会按 Runtime、共享 Node 引擎、回退备份、Task、附件、
图表与证据、日志等分类显示占用。需要释放空间时，可以在确认后清理旧 Runtime
回退备份。

清理不会删除当前 Runtime、最近一个回退点、Task、附件或证据，也不会处理不是
SkillDock 标准命名的备份目录。

安装日志有单独的清理入口，只会删除安装日志目录，不影响 Runtime、Task 或证据。

安全限制
========

- 页面和 Skill 不会自动修改 BIOS、固件、驱动、频率、电压、功耗、风扇、
  内存时序或系统设置。
- 所有硬件设置变更都需要用户自行确认和操作。
- 数据不足时只会给出低风险的补充采集建议，不会把未知结果写成确定结论。

卸载
====

安装包根目录提供统一的 Uninstall.cmd。双击它会在一个流程里移除电脑硬件工作台
Skill、SkillDock Runtime 和快捷入口；共享 Node 引擎与回退备份会按数据保留策略
处理。

默认卸载会保留 Task、附件、证据、导出、共享 Node 引擎和备份，方便以后重装或
继续排查。确实需要彻底清理时，在卸载窗口选择“移除全部本地 SkillDock 数据、
导出和备份”。“彻底清理”不可撤销，执行前请确认已经保存需要保留的证据。

已知限制
========

- 当前面板只支持 Codex 的当前用户对话。
- 当前版本只提供 Windows 64 位安装。
- 分析结果取决于 CSV 的内容、时间范围和采样质量。
- 关闭面板后不会在后台自动继续运行硬件分析。
