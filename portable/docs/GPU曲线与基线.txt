GPU 曲线与当前运行基线

参数仅供参考，请以安全为第一要务。

最短正确路径

1. 保存默认或已知稳定配置，记录一次完整基线。
2. 选择一个固定目标负载，例如固定游戏场景或同一个基准。
3. 先只调核心 V/F 曲线，不改显存和功耗墙。
4. 核心通过后，再单独测试显存。
5. 最后比较不同功耗墙下的持续有效频率和实际帧率/吞吐。
6. 每个准备保留的方案至少重复两次，记录帧时间、最高温度、功耗和限制原因。
7. 通过后验证重启、待机、轻载、睡眠唤醒和数小时实际游戏。
8. 只保留最终胜出的日常档和独立跑分档。

一、先记录当前参数下的运行报告

使用已经确定的固定游戏、固定路线、分辨率、画质和帧率上限。预热后记录一段稳定负载窗口，不要只填待机值或某一个瞬时峰值。

至少记录：

- 显卡型号、驱动版本、调校软件名称和版本；
- 当前配置或曲线名称；
- 游戏、版本、场景、分辨率、画质和采样时间；
- 代表性稳定核心电压（mV）；
- 该电压点对应的核心或有效频率（MHz）；
- 平均/最低 FPS 或帧时间；
- 显卡板卡功耗；
- 核心、热点和显存结温（传感器存在时）；
- PerfCap/限流原因，例如功耗、温度、电压、可靠性或利用率限制；
- 风扇模式、环境温度；
- 是否出现黑屏、驱动重置、画面异常或其他错误；
- 原曲线截图或可恢复的原配置位置。

电压传感器不可用，或无法确定稳定负载平台点时，不要猜电压点，也不要套用他人的曲线。

二、基础 GPU 路线

先把当前默认或已知稳定的 GPU 参数填进实验卡，再选择路线，最后才填写候选值。不要在记录当前参数前就先选曲线拉法。

1. 纯频率超频

不主动降压，也不改变曲线形状。只调整一个核心频率或核心偏移步骤；显存偏移和功耗墙保持不动，并与同一份基线报告比较。

2. 曲线降压超频

1. 在游戏中找到代表性稳定电压和对应核心/有效频率。
2. 在调校软件曲线中找到该电压点。
3. 将目标电压点的频率抬高到本轮候选频率。
4. 将该电压点右侧所有点拉平，避免更高电压继续无意义地推高频率。
5. 如果同时抬高左侧低电压点，把它视为同一候选曲线的一部分，并额外验证待机、轻载和低负载。
6. 显存偏移、功耗墙和其他无关设置本轮保持不动。
7. 先记录原曲线，再保存候选曲线。
8. Apply 后重新打开曲线编辑器，核对最终应用值；工具可能钳制、平滑或调整相邻点，不能只记录拖动目标。

曲线是一个协调变量，不是让你猜一个“万能电压值”。

三、桌面分段曲线方法（笔记本不适用）

这是桌面 GPU 可参考的分段曲线方法：

1. 记录当前有效曲线范围和代表性游戏负载电压。
2. 拉平目标上限电压以上的全部点。
3. 将低电压保护区间保持不动，避免待机和轻载功耗被整体曲线抬升拖高。
4. 只抬升中间电压区间，先以小步开始，再按小步调整。
5. 显存和无关设置保持不动。

RTX 5090 示例参考：

- 1.025V 以上全部拉平；
- 0.8V 以下保持不动；
- 只调整 0.8V~1.025V 区间的曲线；
- 先 +150 MHz，再以 ±15 MHz 或 ±50 MHz 微调。

这些数值只对桌面 RTX 5090 是参考示例。其他桌面 GPU 必须按自己的基线、可见曲线范围和工具行为选择边界，不能直接套用。

笔记本不提供这条桌面分段路线。笔记本先验证受支持的核心路线；不推荐大幅超频显存，确有必要时只做单独的小步测试。

四、桌面 RTX 5090 功耗墙加整段曲线

这是桌面 RTX 5090 专属参考路线，不适用于其他 GPU 或 RTX 5090 笔记本：

1. 功耗墙设置到 93% 作为参考起点；
2. 整段核心曲线先 +150 MHz；
3. 随后以 ±15 MHz 或 ±50 MHz 微调核心频率；
4. 功耗墙和曲线视为一个协调候选，不叠加显存修改；
5. 必须验证待机、轻载、目标游戏、驱动重置和重启。

五、桌面普通显卡的功耗墙上限

仅对满足以下条件的台式机显卡考虑：

- 不是 RTX 4090 或 RTX 5090；
- 散热器和供电设计不是明显缩减的低端版本；
- PSU 型号、额定功率、使用年限、显卡供电线和接头状态可靠；
- 基线确实主要受功耗限制，而不是温度、硬件不稳定或软件故障；
- 温度、热点、风扇和帧时间仍有余量。

满足后，可把厂商工具允许的最高功耗墙作为单独一轮候选。111% 或软件滑块上限只是参考，不是固定安全目标。

如果基线主要受温度限制，应先改善散热或尝试降低功耗墙，不应先拉高功耗墙。

RTX 4090、RTX 5090 需要更保守的高端供电路径和瞬态功率审查，不提供普通拉满路线。

笔记本不提供这条路线。不要使用第三方或修改工具解锁、提高隐藏功耗墙；只使用厂商支持的性能模式和已有控制。

六、验证与停止

必须比较同一游戏、同一路线和同一采样窗口。

验证分为三层：

1. 合成测试或压力测试：只做快速筛选；
2. 目标游戏或生产负载：判断是否值得保留；
3. 待机、轻载、重启、睡眠唤醒和驱动重载：判断能否作为日常配置。

任何 98%～99% 通过率只代表该测试窗口的一致性，不代表所有游戏都稳定。

如果基线显示明显热压力或频率反复冲高回落，可以单独尝试适度降低功耗墙；降低功耗墙后持续频率反而提高并非通用规律，必须用同一负载比较。

显存必须另起一轮。显存请求频率更高不等于带宽或性能更高；若出现错误、纠错开销、花屏或帧率下降，应回退。

停止并恢复原曲线的情形：

- 黑屏、驱动重置、系统重启或游戏崩溃；
- 画面出现点状、闪烁、条纹或其他伪影；
- 待机、视频播放或轻载时异常；
- 频率突然塌陷或性能无故下降；
- 温度或功耗行为明显超出准备范围；
- 重启后曲线未按预期恢复。

通过目标游戏测试只代表本轮可继续；还需要待机、轻载、重启和日常使用观察，才能判断是否适合长期保留。

七、恢复顺序

关闭调校工具 → 恢复原厂或已知稳定配置 → 禁用自动应用 → 重启并检查曲线、功耗墙和风扇模式 → 驱动异常时按官方流程重装或回滚 → 先观察稳定，再继续实验。
