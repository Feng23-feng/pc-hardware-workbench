电脑硬件便携工具包 1.4.3

适用场景

这是一个不需要 Codex、不需要 API、不需要安装的 Windows 本地工具。双击“开始使用.cmd”进入菜单。

核心目标不是替使用者调好，而是教使用者学会识别平台、建立基线、一次只改一个变量、验证结果并恢复原厂。最终目标是下次可以自己完成调校闭环。

功能

0. 我不知道选什么
   选择新手模式。工具不会先让你理解“快速/深入”“脱敏”或“预热秒数”，而是先问你现在最想解决哪件事。

1. 读取电脑配置
   进入后再选择报告模式：
   - 标准模式：保留精确电脑、主板或笔记本、BIOS、内存料号、硬盘型号和显示器 ID。适合自己的电脑或可信排障，分析最准确；分享给他人要谨慎。
   - 隐私脱敏：隐藏型号级标识，保留容量、速度、核心/线程、接口、映射、电池健康和显示/HDR 能力。适合公开发送，但型号级兼容、保修和残值判断精度会下降。

   1.2.1 起，采集完成还会显示设备身份质量：
   - 可读：系统型号可用于对应平台判断；
   - 部分可读：型号级兼容判断保持保留；
   - 可疑或不可读：不会把异常型号文本当成已确认设备；
   - 隐私脱敏：明确标记为已隐藏，不尝试反推真实型号；
   - CPU、GPU、容量和接口等独立可读信息仍会保留。

2. 分析已有的监控记录
   监控软件可以把温度、频率、功耗和帧率保存成一份记录。这类文件通常叫 CSV，也就是一张表格，文件名一般以 .csv 结尾。

   选择本项后会先确认：
   - 已经安装监测软件并且有记录：进入文件分析；
   - 已安装软件但还没有记录：显示 HWiNFO Sensors-only 记录步骤；
   - 还没有监测软件：显示 HWiNFO 下载、镜像选择和记录步骤；
   - 选择返回时明确说明没有分析记录。

   选择已有记录后，可以填写前面不计入统计的时间和统计时长。工具会汇总可识别的 FPS、帧时间、频率、功耗、温度、热点、显存温度、风扇和 CPU 数据。常用的监控软件是 HWiNFO64 Sensors。

   如果从“0. 我不知道选什么”进入，新手菜单会把两种情况分开：
   - “我想查看温度、频率、功耗等数据，但还没有监控记录”：只说明 HWiNFO 的安装、Sensors-only 和记录生成流程；
   - “我有一份监控软件导出的记录，想分析结果”：这时才询问要分析的文件。

   分析已有记录时可以自动统计整个文件，不需要计算秒数；同时会提醒你，混合了待机、加载和正式负载的数据只能作初步参考。

   1.0.1 起，可直接分析中文界面的 HWiNFO Sensors 记录：
   - 兼容重复列名和灵活日期时间；
   - 自动忽略 HWiNFO 文件尾附加的设备元数据；
   - 优先使用 Presented 平均帧率；
   - 支持 GPU 温度、功耗、有效频率、显存结温、CPU 封装温度与功耗等中文列名。

   还没有记录时，可以从 HWiNFO 官方页面下载当前稳定版：
   https://www.hwinfo.com/download/

   新手默认选择 Installer。Free Download 的三个选项按以下顺序：
   1. Local (U.S.)：官方 hwinfo.com 直链，首选；U.S. 只是服务器位置，不是地区限制；
   2. SAC ftp (SK)：官方页面链接的备用镜像；
   3. dAppCDN (Fast CDN)：最后备用；部分网络实测会超时，不要反复等待。

   DWG FastView、LanSweeper、OPEN、Try Now 等是广告，不是 HWiNFO 下载按钮。不要把 HWiNFO 安装包放进本工具分享包；请从官方页面下载。

   打开时选择 Sensors-only，开始记录并保存为 CSV，运行要测试的游戏或软件，结束后停止记录。HWiNFO 在这里只负责观察，不会修改频率、电压、功耗、风扇或 BIOS。不要从来路不明的网盘、论坛附件或捆绑安装包下载。

   原始 CSV 可能附有设备信息。发给别人时，优先只发工具生成的分析摘要；如果必须发送原文件，先检查并隐藏不需要的设备标识。

3. 超频/降压调校
   先通过统一调校入口检查，再选择快速或深入：
   - 快速：较少记录，适合第一次尝试或日常轻量调校；
   - 深入：额外记录驱动和当前配置，适合长期验证或极限优化。

   GPU 调校前必须先提交当前参数下的固定游戏运行基线。进入实验卡后，先填写当前默认参数，随后才选择路线，最后填写候选值。工具会区分：
   - 纯频率超频：不主动降压，不改变曲线形状，只做一个核心频率或核心偏移步骤；
   - 曲线降压超频：记录游戏中的代表性稳定电压和核心频率，再抬高目标电压点、拉平右侧，必要时处理左侧低电压点。
   - 桌面分段曲线降压：高电压段拉平、低电压保护段不动，只抬中间电压段；笔记本不提供这条路线。
   - 桌面 RTX 5090 功耗墙加整段曲线：93% 功耗墙、整段先 +150 MHz，再以小步微调；不会显示给其他显卡或笔记本。
   - 桌面功耗墙上限测试：仅非 RTX 4090/5090、供电与散热不缩水且 PSU 条件明确的台式机；111% 或软件上限只作为参考，仍需先有功耗受限基线和温度余量。

   1.2.5 起，GPU 基线还必须记录 PerfCap/限流原因；曲线 Apply 后要重新核对实际应用值；跑分、目标游戏和待机/重启属于三个不同验证层级。
   1.2.6 起，普通桌面功耗墙上限路线会核实 PSU、供电路径、接头和限流原因；RTX 4090/5090 和笔记本不会出现该路线。笔记本不要用第三方工具解锁隐藏功耗墙。
   1.2.7 起，检测到 Intel 13/14 代 CPU 会先提示桌面高功耗型号的稳定性/退化风险、BIOS/微码和原盒/散片保修状态；默认不稳定时先排障，不用降压或定频掩盖。外部参考会记录来源和“改了什么、没改什么”。
   1.2.8 起，遥测文件名、列名和警告文本会统一进行 Markdown 安全转义；默认单个遥测文件上限为 512 MB，大文件应先截取固定窗口。
   1.2.9 起，遥测只接受本地文件，拒绝 UNC 和映射网络盘；外部文本统一放入安全代码片段，裸 URL、邮箱和不可见字符不会形成活动内容。
   1.2.10 起，遥测分析器升级到 1.0.7，并拒绝 Windows Offline/云占位文件，避免读取时触发云端下载。
   1.2.11 起，采集器和分析器共用本地路径安全模块，额外拒绝符号链接、目录联接和重解析点；采集器版本 1.0.1-r9。
   1.2.12 起，分析器版本 1.0.9 会清除全部 Unicode 控制字符、格式控制字符和常见变体选择符，避免不可见字符影响终端或 Markdown 显示。
   1.2.13 起，硬件字段统一进入安全 Markdown 文本，库存范围统一为本地固定/移动卷，分析器增加 CPU Core Max 和 GPU Core Voltage；采集器 r10、分析器 1.1.0。
   1.2.14-1.2.17 起，加入日常变慢与截图证据规则；AMD HWiNFO 的 `CPU (Tctl/Tdie)`、`CPU PPT`、`CPU Die (average)` 可被识别，Offset/Limit 列被排除，未选到来源时会报告被拒绝的候选列。

4. 复盘上一轮调校
   自动寻找当前会话或最近一张实验卡，可关联本轮测试 CSV，记录结果、决定理由和下一步，并把复盘写回同一张卡。

5. 打开使用说明

6. 查看 HWiNFO 下载说明（监测软件）
   不用先进入新手模式，也能单独查看官方下载页、Installer/Portable 选择、三个免费下载镜像的优先级和广告识别。

调校入口检查

主菜单直接选择 3，也会先检查五项：

1. 具体平台、目标部件，以及 BIOS 或工具是否真的提供该控制项；
2. 当前原厂或已知稳定配置能正常稳定使用；
3. 本轮要改善什么；
4. 出问题时怎样恢复；
5. 用哪个固定负载、看什么结果、什么异常必须停止。

任一项不能确认，工具不会只把人挡回去，而是显示对应的补齐方法：

- 怎样保存配置、恢复原厂并确认稳定；
- 去哪里检查官方工具或 BIOS 是否真的有控制项；
- 怎样记录原值和找到重置默认入口；
- 怎样用现有游戏、内置基准或渲染任务建立固定比较；
- 主要看什么结果、哪些异常必须停止。

教育完成后仍需重新通过检查，才会生成实验卡；但不会因为用户不懂而只回复“不能继续”。这个检查对所有用户生效，不存在“熟练用户直接跳过”的路径。

超频/降压新手入口的后续流程

- 读取配置单后，不会直接返回菜单；
- 再次进入超频/降压时会自动查找最新配置单，不会默认要求重复采集；
- 可以按回车直接复用最近报告，只有输入 `r` 或选择“重新生成/更新配置单”才重新采集；
- 复用前会提醒：近期更换过 CPU、GPU、内存、硬盘、主板/笔记本、显示器或电源适配器时，应重新采集；
- 调校入口会从配置报告摘要中读取电脑型号、CPU 和 GPU，不再要求重复输入这些平台信息；
- 入口检查已确认的路线、目标、通过/中止条件、恢复方式和工作负载会直接写入实验卡，不重复询问；
- 工具会说明配置单只记录硬件，不能证明控制项、稳定基线或恢复方式；
- 接着提供“继续入口检查并准备实验卡”“重新查看怎样补齐条件”“返回新手菜单”三个选择；
- 即使跳过配置单，也会进入同一后续页面，只要用户已经知道具体平台和部件仍可继续；
- 通过入口检查后，再解释快速/深入实验卡的区别并询问选择。

全模式交互闭环

- 配置采集取消时，明确说明没有生成配置单；
- 监控记录未选择或路径无效时，说明分析已取消或要求重新选择；
- 遥测时间输入不是非负数字时，直接解释示例并重新询问，不丢弃整个分析流程；
- 调校入口必填项留空时，在当前位置提示示例并重试；输入 ? 可查看完整补齐方法；
- “下一步”菜单输错序号会重新显示，不会静默退出；
- 快速/深入实验卡深度输错会重新询问，不再错误声称“已保留检查结果”；
- 唯一主要变量留空会重试，避免填到最后才丢失整轮入口检查；
- 配置完成、分析完成和实验卡生成后都给出明确下一步。

P0 流程连续性

- 调校入口缺项帮助后回到同一问题，已回答内容不丢；
- HWiNFO 下载或记录说明结束后自动回到监控分析确认；
- 有多份配置报告时先显示时间和平台摘要，由用户选择正确电脑；
- 同一设备上一轮实验卡的路线、目标、恢复、负载和判定条件作为默认值；
- 故障和升级入口在采集完成后继续原流程；
- 升级入口改为“升级判断前置整理”，不直接承诺购买结论。
- 配置报告复用前会检查近期硬件变更，避免继续使用过期设备信息。

基于配置的调校预期方向

- 入口检查完成后、选择快速/深入前，工具会显示本轮预期方向和首个验证变量；
- GPU 降温/降噪先考虑单项核心曲线，GPU 性能先核心后显存；
- CPU 降温和 CPU 性能分开，不把 CPU 降压描述成自动提性能；
- 内存先检查 XMP/EXPO 整体配置，再考虑单项时序；
- 笔记本会提示共享功耗和散热预算，台式机也不会被假定存在安全余量；
- 实验卡会保存预期方向、取舍、配置限制、上一轮变量和后续需要的遥测证据；
- 不凭型号套用通用电压/频率数值，也不承诺固定百分比收益。

P1 会话状态与实验跟进

- 当前会话记住已选配置报告、当前平台和最近实验卡；
- 后续调校和复盘不再重复选择同一台电脑；
- 新实验卡状态为“待测试”；
- 复盘后可关联 CSV、记录通过/失败/无结论和保留/继续/回退/停止；
- 复盘结果、理由和下一步会追加到原实验卡，并标记“已复盘”。

P1 后半段

- 调校入口每一题支持 `?` 帮助、`B` 返回上一项、`Q` 取消；
- 从确认摘要按 `B` 可回到逐项检查，并保留已填内容；
- 主菜单 `M` 可切换详细/简洁讲解模式；
- 简洁模式减少重复说明，安全条件和中止条件仍明确；
- 升级入口生成“升级准备”报告，记录痛点、任务、设置、当前表现、目标、预算和待补证据；
- 升级判断按保留、配置、维修、单件替换、平台重建、等待的顺序进行。

实验卡会怎样帮助学习

- 唯一主要变量、原厂基线、通过/中止条件和恢复方式继续保留，因为这些直接影响安全；
- 卡片中的“学习提示”自动列出这些条件，不要求用户从空白开始作答；
- “学习复盘（选填）”只保留四项：最有价值的证据、决定和理由、想记住的一点、仍需帮助的地方；
- 用户可以跳过复盘直接使用实验卡，不把教学变成作业或通关条件。

新手模式会怎样带你

- 先问现实问题，不让你先选内部模式；
- “还没有监控记录”和“已有记录要分析”是两个独立入口，不会默认所有新手已经装过监控软件；
- 配置结果会问“只给自己看”还是“要发给别人看”；
- 故障问题时先给最小安全检查，不盲目让你改 BIOS 或驱动；
- 完全不会却想超频时，不直接给电压和频率，先确认机器、稳定基线、固定负载和恢复方式；
- 快速和深入实验卡入口共用同一套调校入口检查；
- 缺少条件时提供怎样补齐的教学步骤，而不是只显示失败；
- 每轮实验卡提供自动整理的学习提示和可选复盘，目标是逐步脱离帮助但不增加强制作业；
- 想升级时先确认现在到底哪里不够用，不把购买当成默认答案；
- 仍然不知道怎么选时，可以直接进入最安全的只读配置采集。
- 所有取消、输入错误和后续菜单都有明确状态，不会无解释回到开场菜单。

安全边界

- 工具只读、本地运行、不联网、不修改硬件设置。
- 不自动修改 BIOS/UEFI、XTU、ThrottleStop、Afterburner、风扇、功耗、频率、电压或内存时序。
- 不请求管理员权限，不安装驱动，不关闭安全功能，不规避反作弊。
- 不把快速通过当作日常稳定。
- 隐藏的热点或显存温度不能用核心温度或固定温差估算。
- 调校前必须保存已知稳定配置和恢复方式。

自检与实机授权

只检查文件、语法和合成样例，不读取本机硬件：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\start.ps1" -SelfTest
```

确认要额外测试本机只读采集时，必须同时添加授权开关和隐私模式：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\start.ps1" -SelfTest -AllowLiveCollector -CollectorPrivacyMode Redacted
```

- `Redacted`：默认推荐，隐藏设备、主板、BIOS、硬盘和显示器型号；
- `Standard`：保留精确型号，适合自己的电脑或可信排障；
- `Both`：两种模式都测试，耗时稍长。

未添加 `-AllowLiveCollector` 时，实机测试会明确显示 `SKIP`，不会把跳过描述成通过。实机自检只执行只读采集，不修改任何硬件或系统设置。
